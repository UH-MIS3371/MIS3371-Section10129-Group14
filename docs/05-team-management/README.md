# Team participation tracker

[Open the tracker](team-tracker.xlsx).

One sheet: team members down the left, the supplied class activities, group exercises, and milestones across the top, from September 3 through November 22. Scores through October 25 are all **100 (complete)**. For November 1, 8, 15 and 22, the team leader, Sophia and Agah have 100 and the other members have scores from 80 to 100.

Click any score to change it. Scroll right to see later activities; names and headers stay visible. Add future activities in the next column to the right, then save the file.

The **Evidence** sheet lists each member's commits on `main` by month, taken from the repository history, so the scores can be checked against real work.
