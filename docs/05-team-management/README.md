# Team participation tracker

[Open the tracker](team-tracker.xlsx).

One sheet: team members down the left, the supplied class activities, group exercises, and milestones across the top, from September 3 through October 25. Every participation score starts at **100 (complete)**, as requested by the team leader.

Click any score to change it. Scroll right to see later activities; names and headers stay visible. Add future activities in the next column to the right, then save the file.
