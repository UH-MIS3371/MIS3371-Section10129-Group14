    How the whole system works

    MarketStreet is a static website that talks to a small AWS backend. Four short flows show everything: how the site gets to you, how you sign in, what happens when you submit an order, and how you read it back.

    1

    Pushing code to GitHub is the only deploy step.

    How you read an order back

    The confirmation number is the record's key in the database.

    BrowserAsks for the number.
    GET /api/trades/{number}
    API GatewayChecks the token.
     
    LambdaThe owner (and admins) may read it.
    read
    DynamoDBReturns the saved record, or 404.

    Recording this? What to show, in order
    1. Open the deployed site and sign in.
    2. Step 1: choose Valid order, press Submit order, and read the confirmation number aloud.
    3. Step 2: press Retrieve. The same record comes back from the database. Test the number that doesn't exist, then press "Show everything saved" to show the Accepted and Rejected records the database holds.
    4. Step 1 again: try Quantity 0, Too expensive and Sell more than owned. Read each rejection reason. Each is saved as a Rejected record.
    5. Step 3: run the matrix. Point at T11 (largest affordable Buy accepted) and T12 (one more share rejected), then read the summary. Scroll back up to the business rules table: each rule now shows how its tests came out.
