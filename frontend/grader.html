    1. Deploy. A push to GitHub main makes Amplify publish the site.
    2. Load. The browser downloads the HTML, CSS and JavaScript from Amplify.
    3. Sign in. The browser sends the email and password straight to Cognito and receives a token.
    4. Submit. The browser sends the order as JSON with the token to API Gateway.
    5. Check. API Gateway verifies the token. Lambda checks the business rules.
    6. Save. Lambda saves the order and the cash and holdings change together in DynamoDB. A rejected order is saved too, with its reason.
    7. Log. Lambda writes one log line to CloudWatch.
    8. Retrieve (not drawn). A lookup by confirmation number reads the record back from DynamoDB.

    Logos: AWS Architecture Icons (Amazon Web Services), and the GitHub, HTML5, CSS3 and JavaScript logos from Simple Icons. All belong to their owners. On a computer without AWS, local-server.js stands in for API Gateway, Lambda and DynamoDB.

    Recording this? What to show, in order
    1. Open the deployed site and sign in.
    2. Step 1: choose Valid order, press Submit order, and read the confirmation number aloud.
    3. Step 2: press Retrieve. The same record comes back from the database. Test the number that doesn't exist, then press "Show everything saved" to show the Accepted and Rejected records the database holds.
    4. Step 1 again: try Quantity 0, Too expensive and Sell more than owned. Read each rejection reason. Each is saved as a Rejected record.
    5. Step 3: run the matrix. Point at T11 (largest affordable Buy accepted) and T12 (one more share rejected), then read the summary. Scroll back up to the business rules table: each rule now shows how its tests came out.
