Grader check

Each requirement below is checked live against the deployed application, with real requests to the API and real reads from the database. Work down the page, or run the whole test matrix in step 3.

    1 Submit a transaction

    The page sends the order to the API. If the backend accepts it, the response carries a confirmation number.

    2 Retrieve it with the confirmation number

    A second request reads the saved record back from the database using only the number.

    3 Test matrix: valid, invalid, boundary and business rules

    24 cases, each a real request with its expected result written down first. The run starts by resetting your paper account to $10,000.00, then places real orders. Rejected orders are saved as Rejected records. As a guest, the same cases run in your browser and nothing is sent to AWS.
